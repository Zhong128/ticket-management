## 设计与实现约定

品牌玫红#EB1761／深玫红#BE104C，文字#20212A，背景#F7F8FA，白#FFFFFF，线#E9EAF0。中文无衬线，标题24–28px，正文14px。工作台以近期排期、海报和待办突出业务，不生成虚构营收图表。桌面左侧导航＋右侧工作区，移动端折叠菜单和局部可滚动表格。

沿用Vue3、TypeScript、Router、Pinia、Axios与图标，无大型UI库。src/admin集中后台页面、组件与会话。用户外壳与后台外壳隔离，共享请求解析但使用不同Token及失效事件。后端Service规则、具名MyBatis SQL，无业务JDBC。

- 登录骨架：独立会话、权限守卫、布局、公共分页及弹窗、工作台；主任务实施并整合。
- 内容管理：城市分类、演出列表编辑详情、场次、票档库存；独立实施后核对契约。

- 收尾：受控浏览器、隔离MySQL实际Mapper与真实API浏览器、桌面手机截图、用户端回归和同源打包。
